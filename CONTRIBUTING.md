# Contributing

This repository collects reference architectures and test cases for GPU-backed inference on Kubernetes. Keep contributions focused on production inference, Kubernetes GPU operations, NVIDIA serving patterns, guardrails, and measurable benchmark results.

## Guidelines

- Prefer reproducible manifests and scripts over manual steps.
- Document hardware, cloud, image versions, and benchmark settings.
- Separate measured results from conceptual notes.
- Keep explanations grounded in things that can be run, measured, or debugged.
